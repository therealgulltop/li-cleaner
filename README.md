# LI Cleaner

A userscript that hides LinkedIn feed posts that only show up because someone liked, loved, celebrated or commented on them.  If you're connected (1st) to the person who wrote the post, it stays.  Hidden posts shrink to one line with an Undo link, and a counter in the corner shows how many were hidden.  It works on desktop and on LinkedIn's mobile layout (for example in Quetta on Android).

| Script | Install |
|---|---|
| LI Cleaner | [li-cleaner.user.js](https://raw.githubusercontent.com/therealgulltop/li-cleaner/main/li-cleaner.user.js) |

## Install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension.
2. In current Chrome or Edge, open Tampermonkey's extension details page and turn on **Allow User Scripts**.
3. Click the install link above and choose **Install**.

Updates arrive automatically through Tampermonkey.
